
## Формат файла грамматики

```
# Комментарий (игнорируется)
k=2                           # необязательная директива (по умолчанию k=1)
S -> a A a a | b A b a        # правила (альтернативы через |)
A -> b | eps                  # eps = ε-правило
```

Нетерминалы определяются автоматически: это все символы, стоящие в левой
части хотя бы одного правила. Все остальные символы — терминалы.

## Примеры результатов

### Пример 2.2 (стр. 12–16): простая LL(1)-грамматика
```
FIRST_1(S) = { a, b }          FIRST_1(B) = { a, b }
σ(S) = { {eps}, {a,b} }        σ(B) = { {a,b} }
FOLLOW_1(S) = { eps, a, b }    FOLLOW_1(B) = { a, b }
ИТОГ: LL(1) = ДА   |   Сильная LL(1) = ДА
```

### Пример 2.3 (стр. 49–52): несильная LL(2)-грамматика
```
FIRST_2(S) = { aa, ab, bb }    FIRST_2(A) = { eps, b }
FOLLOW_2(A) = { aa, ba }       (совпадает со слайдом 51)
ИТОГ: LL(2) = ДА   |   Сильная LL(2) = НЕТ
```

### Пример 2.6 (стр. 92–96): грамматика арифметических выражений
```
FIRST_1(E) = FIRST_1(T) = FIRST_1(F) = { (, a }
FIRST_1(E') = { eps, + }       FIRST_1(T') = { eps, * }
ИТОГ: LL(1) = ДА   |   Сильная LL(1) = ДА
```

### Пример 2.11 (стр. 201–213): демонстрация σ(A)
```
σ(A) = { {eps, a, b} }         σ(S) = { {eps} }
FOLLOW_1(A) = { eps, a, b }
ИТОГ: LL(1) = ДА   |   Сильная LL(1) = ДА
```

## Связь с теорией (ключевые определения из лекций)

**Определение 2.12 (σ(A)):**
```
σ(A) = { L ⊆ VT^*k | S =>*_lm wAα, w∈VT*, L = FIRST_k(α) }
```

**Вспомогательная функция σ'(A,B):**
```
σ'(A,B) = { L ⊆ VT^*k | A =>*_lm wBα, w∈VT*, L = FIRST_k(α) }
σ(A) = σ'(S, A)
```

**Теорема 2.1 (критерий LL(k)):**
G — LL(k) ⟺ для всех A→α, A→β ∈ P (α≠β), для всех L∈σ(A):
```
(FIRST_k(α) ⊕_k L) ∩ (FIRST_k(β) ⊕_k L) = ∅
```
